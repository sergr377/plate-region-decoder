# Plate Region Decoder

Мобильное приложение на Expo/React Native для быстрой расшифровки кода региона на автомобильных номерах РФ.

## Как это работает

1. Приложение открывается сразу на экране ввода — фокус на клавиатуре не нужен.
2. Пользователь набирает код региона (1–3 цифры) на зафиксированной цифровой клавиатуре.
3. Начиная со второго введённого символа, поиск по справочнику кодов идёт при каждом нажатии — подтверждать ввод не нужно.
4. Результат выводится текстом и подсвечивается на контурной карте РФ с анимированным зумом к найденному региону.

Кнопка `⌫` очищает весь ввод целиком. При попытке ввести 4-й символ текущий ввод сбрасывается, и новая цифра становится первой.

## Стек

- [Expo](https://docs.expo.dev/) SDK 54 / React Native 0.81
- [react-native-svg](https://github.com/software-mansion/react-native-svg) — контурная карта регионов
- [EAS Build](https://docs.expo.dev/build/introduction/) — сборка нативных APK/AAB

## Структура проекта

| Файл | Назначение |
|---|---|
| `App.js` | Основной экран: клавиатура, поле ввода, результат |
| `regions.js` | Справочник кодов регионов → название субъекта РФ |
| `RussiaMap.js` | SVG-компонент контурной карты с анимированным зумом |
| `russiaMapData.json` | Геоданные 83 субъектов РФ (пути SVG + координаты центров) |
| `eas.json` | Профили сборки EAS (`preview` → APK, `production` → AAB) |

Контурная карта покрывает 83 субъекта РФ, существовавших до 2014 года. Коды Крыма, Севастополя, ДНР, ЛНР, Херсонской и Запорожской областей распознаются и выводятся текстом, но не подсвечиваются на карте — исходный геодатасет их не включает.

## Запуск в разработке

```bash
npm install
npx expo start
```

Отсканируйте QR-код приложением [Expo Go](https://expo.dev/go) на телефоне (Android/iOS) — версия SDK в Expo Go на вашем устройстве должна совпадать с версией проекта (SDK 54).

## Сборка APK

Сборка выполняется в облаке через EAS и не требует локально установленных Android SDK/Xcode.

```bash
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

По завершении EAS выдаст прямую ссылку на скачивание `.apk`. Профиль `preview` собирает APK только под архитектуру `arm64-v8a` с включённой минификацией — это подходит для установки на большинство современных Android-телефонов и даёт заметно меньший размер файла, чем универсальная сборка под все архитектуры сразу.

Для публикации в Google Play используйте профиль `production` (собирает `.aab`):

```bash
npx eas-cli build --platform android --profile production
```
